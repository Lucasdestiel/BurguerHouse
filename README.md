# Burger House — Cardápio digital

Projeto demonstrativo de cardápio digital responsivo com carrinho e finalização de pedido pelo WhatsApp.

## Personalização obrigatória antes de publicar
1. Em `js/app.js`, altere `STORE.whatsapp` para o número real da hamburgueria, com DDI + DDD + número, apenas dígitos.
2. Atualize endereço, telefone e horários em `index.html`.
3. Revise nomes, descrições, preços e imagens no array `products`, em `js/app.js`.
4. Troque as imagens demonstrativas por fotos autorizadas dos produtos.

## Tecnologias
HTML5, CSS3, Bootstrap 5, JavaScript e LocalStorage.

## Observação
O pedido é montado no navegador e enviado ao WhatsApp por link `wa.me`. O cliente ainda precisa confirmar o envio dentro do WhatsApp. Não há pagamento online nem painel administrativo nesta primeira versão.
